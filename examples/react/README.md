# App React vulnerável de propósito

Use `pnpm secmentor scan examples/react` sem instalar dependências. Para abrir a demonstração isolada:
`npm install --ignore-scripts` e `npm run dev` nesta pasta. Só use a máquina local e conteúdo fictício.
A interpolação React (`<article>{bio}</article>`) é a alternativa para mostrar texto sem HTML bruto.
