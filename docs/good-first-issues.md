# Tarefas para começar

Esta lista descreve oito issues prontas para copiar ao GitHub. São propostas locais; não foram criadas remotamente.

1. **[good first issue] Explicar parâmetros SQL com uma segunda analogia.** Escopo: SM001.yaml. Pronto quando a analogia evita jargão, mantém precisão e passa lint-lessons.
2. **[good first issue] Fixture de textContent com JSX.** Escopo: testes SM002. Pronto quando código seguro não alerta e o caso vulnerável equivalente alerta.
3. **[good first issue] Exemplo de revogação sem fornecedor específico.** Escopo: SM003.yaml. Pronto quando a lição distingue apagar do Git e revogar a chave.
4. **[good first issue] Melhorar explicação de salt.** Escopo: SM004.yaml. Pronto quando explica por que o salt pode ser público sem prometer proteção absoluta.
5. **[good first issue] Documentar diferença entre .env e .env.example.** Escopo: guia e fixtures SM005. Pronto quando um template fictício não alerta e arquivo rastreado alerta.
6. **[good first issue] Quiz adicional sobre setTimeout.** Escopo: SM006.yaml. Pronto quando opções são distintas, explicação é acolhedora e índice passa Zod.
7. **[good first issue] Tradução revisada de SQL injection para inglês.** Escopo: lessons/en. Pronto quando todos os campos estão completos e o pacote é validado sem substituir pt-BR.
8. **[good first issue] Revisão manual de teclado no playground.** Escopo: checklist em docs. Pronto quando registra foco, seletor de exemplos, filtros, abas e quiz em duas larguras, com reprodução de qualquer bug encontrado.
